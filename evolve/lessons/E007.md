# E007 · 改预设前先确认改的是哪个目录

**作用域**：always
**命中条件**：被要求修改预设或工作流时
**原添加日期**：2026-09-19
**原 hits**：1

## 正文

先确认改的是 **workflow-v2** 目录，**不动** `workflow-cordis` 与出厂 `cordis`。

## 为什么

本机同时存在多套预设/组合：

| 名称 | 性质 |
|---|---|
| `workflow-v2`（本目录） | 自建，用于按工作流执行 |
| `workflow-cordis` | 自建，用于创作 preset（含 `tool-cordis`） |
| 出厂 `standard` / `ptc` / `minimal` / `cordis` | 来自 `@deepseek-ai/dsh-web-app` bundle，**升级会覆盖** |

改错对象的两类后果：

1. 改了出厂预设 → 下次 `dsh` 升级**被静默覆盖**，改动丢失
2. 改了 `workflow-cordis` → 那是创造模式的预设，改坏会影响「用 agent 造 agent」的能力

## 怎么判断

改动前先看路径：`~/.dsh/presets/<name>/` 才是可改的自建预设。
出厂预设位于 `node_modules/@deepseek-ai/dsh-web-app/presets/`，**只读不改**
（要改就 override 它的 `preset-<id>` 行，而不是编辑该文件）。
