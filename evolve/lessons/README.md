# lessons · 长条目正文

`evolve/ledger.md` 的活跃区只放**短条目**（≤60 字符）。
超长的条目在这里存全文，ledger 里只留一行索引。

## 为什么这样分

`workflow.md` 的 L1 区（骨架）+ ledger 编译结果 = **每次会话都注入的常驻段**，
受 `workflow.mjs` 的 `MAX_L1 = 1500` 字符硬门禁约束。

长条目直接留在 ledger 会把常驻段撑爆，触发 fail-closed（整段不注册 → 工作流全部失效）。
所以：**短句进常驻，全文放这里，需要时 `read`。**

## 读取方式

ledger 里的索引行形如：

```
- [E013 | always | 包装外部程序时] 判据用产出物，不用退出码 → lessons/E013.md
```

看到 `→ lessons/Exxx.md` 就 `read` 该文件拿完整正文。
