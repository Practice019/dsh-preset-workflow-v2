# 进化账本（ledger）

> **这是进化的源文件。** `workflow.md` 的 L1 区是**编译产物**，不要直接改它。
> 每次开会话时 `workflow.mjs` 会自动读本文件 → 编译 → 注册 L1 常驻段（本会话即最新）。

## 怎么加规则

**用 `edit` 工具**在下面 `LEDGER:BEGIN/END` 之间追加一行（模型本身就有 edit 工具）：

```
- [E007 | always | 命中条件] 规则正文   (added: 2026-09-19, hits: 0)
```

**注意**：
- `id` 取已有最大编号 +1（已有 E006 → 新条目 E007）
- **追加前先扫一遍已有条目避免重复**（去重靠人工 —— 原计划的 `evolve.add` 专属工具在预设插件内注册后不进入 agent 可见集，已移除，原因见 `workflow.mjs` 注释）
- **只追加/修改/删除单条，禁止整文件重写**
- 改完**开新会话**即生效（自动编译）

## 条目格式

```
- [id | 作用域 | 命中条件] 规则正文   (added: YYYY-MM-DD, hits: N)
```

- `id`：稳定标识，用 `E001` 递增
- `作用域`：`always`（每轮生效）或具体阶段 `P0..P6`
- `命中条件`：什么时候该想起这条
- `hits`：被实际触发的次数（人工维护；原计划用 `sessionQuery` 自动统计，待验证）

## 硬规则

1. **只能追加 / 修改 / 删除单条，禁止整文件重写**（防 context collapse 与 brevity bias）
2. 新增前先与已有条目做 `作用域 + 关键词` 比对，**命中就 `hits++` 不新增**
3. 触发写入的硬信号只有三类：**工具/命令报错**、**用户明确纠正**、**同一错误第 2 次出现**
4. 零命中超 20 个会话 → 下沉到 `lessons/`，活跃集只留索引行
